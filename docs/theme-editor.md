# Theme Editor

Mode Atelier은 운영자가 코드 수정 없이 주요 브랜드 표현을 조정할 수 있도록 설계한다.

## 전역 디자인 설정

Theme settings → Brand:

- Background
- Text
- Accent
- Muted text
- Page width: 1200–1600px
- Button corner radius: 0–24px
- Media corner radius: 0–24px

## 홈 편집 가능 영역

- Announcement
- Header navigation
- Editorial hero
- Featured collection
- Lookbook
- Brand story
- Newsletter
- Footer navigation

## 콘텐츠 페이지

- 기본 page
- Lookbook template
- Contact template
- FAQ template
- Collections index

FAQ는 `Content accordion` block을 추가/삭제/정렬해 운영한다.

## 운영 원칙

테마 설정값은 브랜드 표현을 위한 옵션이지, 결제/배송/시장 정책의 source of truth가 아니다. 운영 정책은 Shopify Admin의 Payments / Markets / Shipping / Policies를 기준으로 관리한다.
