# Project Brief

## 프로젝트

**Mode Atelier — 글로벌 패션 브랜드 Shopify 커머스 구축 포트폴리오**

## 배경

브랜드 로고와 상품 이미지 정도만 준비된 신규 패션 브랜드가 국내외 고객을 대상으로 공식 사이트 겸 쇼핑몰을 런칭한다고 가정한다. 내부 개발 인력이 없고 상세 메뉴/정책이 미확정된 상태에서 파트너가 정보구조, 테마 구축, 글로벌 판매 설정, QA와 인수인계까지 책임지는 외주 상황을 재현한다.

## 성공 기준

1. 상용몰에 가까운 패션 브랜드 UX
2. Shopify Online Store 2.0 편집 가능 구조
3. 상품 → 장바구니 → checkout 진입 핵심 흐름
4. KO / EN / JA storefront locale
5. 결제/배송/시장 의존성을 허위 완료 없이 문서화
6. 모바일/데스크톱 회귀 검증 체크리스트
7. CI Theme Check 통과
8. 운영자가 테마 설정과 콘텐츠를 수정할 수 있는 인수인계 문서

## 비범위

- 실제 merchant의 PG 계약 및 심사
- 실제 결제 승인/정산
- 실제 도메인 소유권 검증
- 실제 배송사 계약
- 법률·세무 자문
- 실제 고객 개인정보 처리

## 원칙

실제 외주처럼 보이는 것이 목표지만, 실제 계정이나 외부 승인이 필요한 항목을 가짜로 완료 처리하지 않는다.
