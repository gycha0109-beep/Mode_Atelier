# Password / Coming Soon

Mode Atelier에는 오픈 전 브랜드 티저와 private access를 위한 `password.json` + `layout/password.liquid`가 포함된다.

## 제공 기능

- 브랜드 런칭 카피
- Shopify storefront password form
- launch email signup
- Theme Editor에서 heading/text 수정

## 개발 스토어 제한

Shopify development store는 외부 방문자에게 development store 전용 password page를 보여주므로 커스텀 password page가 외부 접근 제어 화면으로 사용되지 않는다.

로그인한 상태에서:

```text
https://<store>.myshopify.com/password
```

로 커스텀 디자인을 확인하고 편집할 수 있다.

실제 merchant store로 이전한 뒤 Online Store password protection을 사용할 때 최종 사용자용 coming-soon page로 검증한다.
